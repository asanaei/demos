About this implementation

        
      

      

        
Data generation

        
Each run simulates n observations from a multivariate Gaussian distribution with mean vector mu and covariance matrix Sigma. The app eigen-decomposes Sigma = V diag(lambda) V' and generates X = mu + Z diag(sqrt(lambda)) V', where Z contains independent standard normal draws from a seeded generator using a Box-Muller transform.


        
PCA

        
The data are always centered. If Standardize is on, each variable is also divided by its sample standard deviation, so PCA is done on the sample correlation matrix. If Standardize is off, PCA is done on the sample covariance matrix. Eigenvalues and eigenvectors are computed with a Jacobi rotation solver. Scores are centered or standardized data times eigenvectors. Loadings are eigenvectors times sqrt(eigenvalue).


        
Scree and retention

        
The scree plot shows the observed eigenvalues. When Standardize is on, the horizontal line at 1 gives the Kaiser reference. The second reference is a 95th percentile parallel-analysis line from Gaussian null data with the same sample size and number of variables.


        
Invalid Sigma

        
If Sigma is not positive semidefinite, the run does not use it directly. The app clips negative eigenvalues to a tiny positive floor, reconstructs a positive semidefinite matrix, rescales it to keep the user-entered variances on the diagonal, and shows a warning. The table labeled Sigma used shows the matrix actually used for the simulation.


        
Notes

        
The signs of eigenvectors, scores, and loadings can flip without changing the PCA solution. Hover over the ? icons for short definitions.
