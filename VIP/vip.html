Quick Tips
  • Collinearity: Set Corr(x1,x2) near 0.9 and put only x1 in the formula. Importance often spreads across x1 and x2.
  • Cardinality bias: Discretize x3 and use impurity importance. x3 can look weaker than a continuous feature with the same effect size.
  • Mitigation: Use permutation importance, and compute it on the test set.
Interpretation Notes
Importance answers: "How useful is this feature for prediction under this model and data distribution?"
It does not automatically answer: "Which variable is uniquely causal?" or "Which variable matters if I intervene?"

Help: What this demo is designed to teach
1) Two importance measures
  • Impurity importance sums split gains during training. It is fast, but can be biased.
  • Permutation importance measures test-set performance drop after shuffling one feature. It is slower, usually more interpretable.
2) Two classic pitfalls
  • Collinearity: correlated predictors share signal. Importance often gets divided across them even if only one is truly in the formula.
  • Cardinality: continuous predictors have many possible split points; impurity-based measures can over-credit them relative to low-cardinality variables.
3) What to try
Collinearity experiment:
Corr(x1,x2) = 0.9
Formula = x1
Importance = impurity OR permutation
Cardinality experiment:
Discretize x3 = checked
Formula = x1 + 0.2 * x3
Importance = impurity (then compare to permutation)
Implementation note: This demo uses a transparent, educational random forest implementation. It follows the standard random forest idea of sampling mtry features at each split.
