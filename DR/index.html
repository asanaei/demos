About this Implementation

Data Generating Process: This demo simulates an N × N binary matrix image grid with a line drawn from the center outward at various angles (0° to 360°), forming a circular "clock hand" manifold. Microscopic Gaussian noise is added to prevent perfectly duplicated rows which mathematically fracture non-linear neighborhood algorithms.

Pure JS Implementation: Classic algorithms like Isomap, LLE, and LE are executed completely within your browser via optimized local matrix manipulation (Power Iterations, Gaussian Elimination, Shortest Path tracing).

UMAP & t-SNE: We utilize the official umap-js and tsnejs libraries for authentic, production-grade output distributions identical to their Python counterparts.

Scree Plot (Intrinsic Dimensionality): The Scree plot dynamically computes the variance explained by the top 10 Principal Components of the raw data. Watch how increasing the Gaussian noise flattens the curve, indicating a shattered manifold!
