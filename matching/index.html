Reading the picture

Each dot is a respondent, placed by age and ideology. Support for the policy without the ad, Yi(0), peaks at the ideological center and declines with age, as the regression panel shows. Because the ad reached older and more extreme respondents, the naive difference in support confounds the effect of the ad with the effect of who saw it. The true effect is set in the survey controls, at eight points unless you change it.

Matching does not model the outcome. It draws from the original sample a subset, with weights, whose covariate distribution resembles that of the treated, and then compares outcomes (Ho et al. 2007). Compare the marginal curves of the two planes: in the original sample the groups differ, in the matched sample they nearly coincide. The cost is information, since controls without a treated counterpart contribute nothing.

Balance, not the estimate, is how one judges a matching, and it must be checked on the functions of the covariates that matter for the outcome. The linear propensity model, e(X) = Pr(T = 1 | X) fitted with straight terms, draws straight contours and cannot see that both extremes were targeted. Matched groups then agree in mean ideology, which was never the problem, and disagree in extremity, which is. Adding squared terms repairs the model. Even so, pairs close in the score may lie far apart in age and ideology, which is why King and Nielsen (2019) argue against matching on it.

Raise the selection and common support thins: some treated respondents have no comparable control. Matching one to one without replacement then reaches for distant controls, and the estimate drifts. A caliper, or finer bins, refuses such comparisons, at the price of discarding treated respondents. With the effect varying by person, the estimate then describes only the treated who were kept, which is a different quantity from the effect on all who saw the ad (Iacus, King, and Porro 2012).

Now raise the unmeasured confounder. The observed covariates balance as before; the hidden trait does not, and no balance table can reveal it, since it is not in the data. Matching rests on the assumption that exposure is as good as random once the measured covariates are held fixed (Rosenbaum and Rubin 1983). Sensitivity analysis asks how strong a hidden confounder would need to be to overturn a conclusion (Rosenbaum 2002).

The repeated samples separate bias from noise. Calipers, finer bins, and replacement lower the bias and widen the spread. Additional controls per treated respondent narrow the spread but, without replacement, admit worse matches. Even good settings leave a small bias, because matches on continuous covariates are never exact (Abadie and Imbens 2006). Raise the share treated toward one half and matching without replacement runs out of good controls; a larger sample shrinks the spread of every estimator but leaves the naive one exactly as biased.

The same analysis in R

The script simulates the same survey, fits the naive comparison and the regression, and matches with each method. It needs tidyverse, MatchIt, and cobalt, and runs from top to bottom. Its sample differs from the one above, so its numbers will too; the matching panel shows the matchit() call for the current settings.

# Matching in practice: the simulated survey behind the matching demo
#
# Respondents either saw a campaign ad (treat = 1) or did not (treat = 0).
# The ad reached older and more ideologically extreme respondents, and both
# traits shape support for the policy the ad promotes.

library(tidyverse)
library(MatchIt)
library(cobalt)

set.seed(42)


# ---- 1. Settings and the model of support -----------------------------------------

n             <- 400   # respondents
share_treated <- 0.20  # about this share sees the ad
true_effect   <- 8     # effect of the ad on support, in points
selection     <- 1     # how strongly age and ideology drive exposure (0 = random)
hidden        <- 0     # strength of an unmeasured confounder (try 1)
varying       <- 0     # set to 1: the ad persuades moderates more than partisans

# Support for the policy, given a respondent's traits and whether they saw the ad.
# It peaks at the ideological center, falls with extremity and with age,
# and rises with the ad.
support_fn <- function(age, ideology, treat, hidden_trait = 0, noise = 0) {
  without_ad <- 70 - 6 * ideology^2 - 0.25 * (age - 48)
  ad_effect  <- true_effect - varying * 3 * (abs(ideology) - 0.8)
  without_ad + treat * ad_effect - 5 * hidden * hidden_trait + noise
}


# ---- 2. Generate the data -------------------------------------------------------

age <- rnorm(3 * n, mean = 47, sd = 15)
age <- age[age >= 18 & age <= 88][1:n]   # keep the first n ages between 18 and 88

ideology     <- rnorm(n)   # liberal (negative) to conservative (positive)
hidden_trait <- rnorm(n)   # shapes exposure and support, but no analyst observes it

# Exposure is more likely for older and for more extreme respondents
index <- selection * (0.84 * abs(ideology) + 0.024 * (age - 48)) + hidden * hidden_trait
treat <- rbinom(n, size = 1, prob = plogis(qlogis(share_treated) - mean(index) + index))

# Each respondent's support without and with the ad: the two potential outcomes
noise     <- rnorm(n, sd = 6)
support_0 <- support_fn(age, ideology, treat = 0, hidden_trait, noise)
support_1 <- support_fn(age, ideology, treat = 1, hidden_trait, noise)

effect  <- support_1 - support_0                       # each respondent's effect
support <- if_else(treat == 1, support_1, support_0)   # what the survey records

survey <- tibble(age, ideology, extremity = abs(ideology), hidden_trait,
                 treat, support, effect)

# The target: the average effect among those who saw the ad (the ATT)
true_att <- mean(effect[treat == 1])

survey |> count(treat)
true_att


# ---- 3. Look at the data -----------------------------------------------------------

ggplot(survey, aes(age, ideology, color = factor(treat))) +
  geom_point()

survey |>
  pivot_longer(c(age, ideology, extremity), names_to = "covariate") |>
  ggplot(aes(value, color = factor(treat))) +
  geom_density() +
  facet_wrap(~ covariate, scales = "free")

# Average support in each group: it peaks at the ideological center
# and falls steadily with age
ggplot(survey, aes(ideology, support, color = factor(treat))) +
  geom_smooth(se = FALSE)

ggplot(survey, aes(age, support, color = factor(treat))) +
  geom_smooth(se = FALSE)


# ---- 4. The naive comparison and the regression ---------------------------------------

fit_naive   <- lm(support ~ treat, data = survey)
fit_linear  <- lm(support ~ treat + age + ideology, data = survey)
fit_squared <- lm(support ~ treat + age + ideology + I(ideology^2), data = survey)

coef(fit_naive)["treat"]     # the naive difference in means
coef(fit_linear)["treat"]    # the regression on the slides
coef(fit_squared)["treat"]   # adding ideology squared, the true shape of support

# Why the linear regression misses: it fits two parallel straight lines (solid),
# while support peaks at the ideological center (dashed). Both are drawn at age 48.
b <- coef(fit_linear)

lines <- expand_grid(ideology = seq(-3, 3, by = 0.05), treat = c(0, 1)) |>
  mutate(
    fitted = b["(Intercept)"] + b["treat"] * treat + b["age"] * 48 + b["ideology"] * ideology,
    truth  = support_fn(age = 48, ideology, treat)
  )

ggplot(survey, aes(ideology, support, color = factor(treat))) +
  geom_point(alpha = 0.3) +
  geom_line(data = lines, aes(y = fitted)) +
  geom_line(data = lines, aes(y = truth), linetype = "dashed")


# ---- 5. Matching ---------------------------------------------------------------------------
# MatchIt's defaults: nearest-neighbor matching, one to one, without replacement,
# on a propensity score from a logit, estimating the ATT

# Coarsened exact matching. Each covariate is cut into 5 equal-width bins, and
# respondents are grouped by the cell they share. Cells lacking either treated or
# control respondents are dropped; in the rest, controls are weighted so that a
# cell's controls count as much as its treated.
m_cem <- matchit(treat ~ age + ideology, data = survey,
                 method = "cem", cutpoints = list(age = 5, ideology = 5))

# Nearest-neighbor matching on the Mahalanobis distance, which measures age and
# ideology in standard deviations. Each treated respondent, in turn, is paired
# with the closest control not yet used.
m_maha <- matchit(treat ~ age + ideology, data = survey, distance = "mahalanobis")

# The same with replacement: each treated respondent gets its closest control,
# even one already used. Bias falls, but reused controls carry more weight,
# so the variance rises.
m_maha_repl <- matchit(treat ~ age + ideology, data = survey, distance = "mahalanobis",
                       replace = TRUE)

# Propensity score matching. A logit of treatment on age and ideology gives each
# respondent a score, and respondents are paired on that single number. A logit
# linear in ideology cannot see that both extremes were targeted.
m_ps_linear <- matchit(treat ~ age + ideology, data = survey)

# The same with squares and the interaction in the logit, so that the score
# can rise toward both ideological extremes.
m_ps_squares <- matchit(treat ~ age + ideology + I(age^2) + I(ideology^2) + age:ideology,
                        data = survey)

# The same with a caliper: a treated respondent is matched only to a control
# within 0.2 standard deviations of its score. Those without one are dropped,
# so the estimate describes only the treated who remain.
m_ps_caliper <- matchit(treat ~ age + ideology + I(age^2) + I(ideology^2) + age:ideology,
                        data = survey, caliper = 0.2)

summary(m_ps_linear)


# ---- 6. Distributions in the matched samples ---------------------------------------------
# match.data() keeps the matched units and adds their weights

matched <- bind_rows(
  "No matching"              = survey |> mutate(weights = 1),
  "Coarsened exact"          = match.data(m_cem),
  "Mahalanobis"              = match.data(m_maha),
  "Mahalanobis, replacement" = match.data(m_maha_repl),
  "Propensity, linear"       = match.data(m_ps_linear),
  "Propensity, squares"      = match.data(m_ps_squares),
  "Propensity, caliper"      = match.data(m_ps_caliper),
  .id = "method"
) |>
  mutate(method = fct_inorder(method))

ggplot(matched, aes(age, color = factor(treat), weight = weights)) +
  geom_density() +
  facet_wrap(~ method)

ggplot(matched, aes(extremity, color = factor(treat), weight = weights)) +
  geom_density() +
  facet_wrap(~ method)


# ---- 7. Results ------------------------------------------------------------------------------
# truth is the true effect among the treated who were kept; it differs from
# true_att only when treated respondents are dropped and varying = 1

matched |>
  group_by(method) |>
  summarise(
    treated  = sum(treat == 1),
    controls = sum(treat == 0),
    estimate = weighted.mean(support[treat == 1], weights[treat == 1]) -
               weighted.mean(support[treat == 0], weights[treat == 0]),
    truth    = mean(effect[treat == 1])
  )

# Balance for every method. With hidden <- 1, add + hidden_trait to the formula:
# matching balances what is measured, not what is not
love.plot(treat ~ age + ideology + extremity, data = survey,
          weights = list(cem = m_cem, maha = m_maha, maha_repl = m_maha_repl,
                         ps_linear = m_ps_linear, ps_squares = m_ps_squares,
                         ps_caliper = m_ps_caliper),
          s.d.denom = "treated", abs = TRUE, thresholds = 0.1)
